## 三、关键技术发现（踩过的坑，别再踩）

1. **MCP 云库工具权限跟随对话者账号环境**——不是能「修好」的东西。解法是绕过：公开 REST 通道不校验账号。
2. **REST 通道只认请求头** `x-wb-webapp-access-key: <publishableKey>`。query 参数（apikey / access_key / token）、`Authorization: Bearer`、`Basic`、`X-Sharecode` 全部 401。
   - 这把钥匙本来就随网页发给每个访客，写进提示词不算泄密。
   - POST 不存在的表返回 404（而非 401）＝鉴权已放行，匿名写权限成立。
3. **域名有 sharecode 门禁**：首次必须带 `?sharecode=YEX2LGOS5J` 访问，种下 `__wb_rsc` cookie 后静态资源才放行。curl 直接抓 `/assets/*` 不带 cookie 会拿到「链接不完整」页，**别误判成部署失败**；发给评委的链接必须整段复制，不能删参数。
4. **平台静态托管不发 `Cache-Control`**：每次发版后内置 WebView 可能仍显示旧页面，需 **Cmd+Shift+R** 强刷（或关掉预览重开）。
5. **聊天里 URL 必须用 `[文字](网址)`**：放进反引号/代码块渲染器不会转成可点链接——这是「只能复制粘贴」的真凶。
6. **扣积分格局**：模型对话轮次扣说话者；REST 数据读写不扣；网页纯浏览不扣；网页 AI 核验走属主（免费档兜底）。
