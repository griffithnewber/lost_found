# 公开信息改造说明书（P0 · 隐私与防冒领）

> 状态：**待实施**（本文件只是需求与改动说明，代码尚未改动）
> 起因：广场卡片目前展示 AI 对图片的解读（如"米白色带樱花图案的便携咖啡杯，杯盖和握绳…"），
> 等于把可复制的物品特征公开给了所有人，**AI 出题核验形同虚设，防冒领失效**。
> 目标原则：**公开页面上出现的每一个字、每一张图，都必须是用户自己写的 / 自己选的。
> AI 只在后台干活（检索打分、出题、判答），绝不在前台说话。**

---

## 1. 两类发布的公开面规则（核心设计）

| | 😢 失者发布（lost） | 🙋 拾者发布（found） |
|---|---|---|
| 谁会来"认领" | 没人认领，是拾到者主动联系失主 | 失主来认领，走 AI 核验 |
| 图片 | **实物图公开**（帮别人认出，公开不构成冒领风险） | **不显示实物图**：显示"类别 emoji + 主色调"卡通占位卡（后续可加 canvas 模糊图，见 §6 可选） |
| 文字 | 用户自己写的**寻物启事**（新增 `notice` 字段），例："有没有人在 11 月 4 日下午在图书馆三楼看到一个米白色水杯？杯盖是粉色的。" | 用户自己写的**一句话拾获说明**（同一个 `notice` 字段），例："11 月 4 日在图书馆三楼捡到一个杯子，.describe 大概样子可以私信对" |
| AI 解读 | **一律不展示**。内部仍可为检索生成（见 §3），但任何页面不得渲染 | **彻底不生成、不存储**（省 token 且零泄露） |
| 标题 | 自由填写 | **泛化**：不允许出现品牌/型号/独特征，用类别下拉生成（"头戴式耳机"而不是"黑色索尼 WH-1000XM4"） |
| 位置 | 区域级即可 | 区域级（"图书馆一带"），不精确到座位 |

一句话总结：**公开信息量与认领风险成反比。**

## 2. 字段变更（A · 数据库 + api.js）

```sql
-- 云库迁移（A 执行，一次）
ALTER TABLE lost_items ADD COLUMN IF NOT EXISTS notice TEXT;
ALTER TABLE lost_items ADD COLUMN IF NOT EXISTS category TEXT;    -- 拾者发布用：类别 key
ALTER TABLE lost_items ADD COLUMN IF NOT EXISTS color_tone TEXT;  -- 拾者发布用：主色调 key
```

- `api.js` 的 `rowToItem` / `itemToRow` / `updateItem` 增加上述三字段的映射；
- `ai_desc` 保留字段，但定位降级为**纯内部检索字段**：
  - 拾者发布：**不再生成**（发布流程跳过 `describeImage`），旧数据里的 ai_desc 展示层忽略；
  - 失者发布：**可以继续生成**（供图片检索匹配用），但**任何页面不渲染**（§3）。

类别与主色调的固定选项（放进 `config.js`，B 的下拉直接引用）：

```
category: headphones / cup / umbrella / card / keys / bag / phone / book / other
color_tone: black / white / gray / blue / red / pink / green / yellow / other
```

## 4. 检索与统计适配（C · search.js / stats.js）

- `search.js:63` 文字检索的 haystack：把 `aiDesc` 替换为 `notice`（+title+category 的中文标签）；
- `search.js:85-94` 图片检索：失者发布物品仍有 ai_desc 可做语义主信号；**拾者发布物品没有** → 用 `category + color_tone` 做粗筛主信号，颜色特征退为加分项；
- `stats.js:26` 统计取词同样换成 `notice`；
- 广场关键词筛选（`square.js:35`）同步换字段。

## 6. 可选增强（本期不做，留档）

- 拾者发布支持上传 canvas 重度模糊图（32×32 放大 + 高斯），原图仅存发布者本机 IndexedDB；
- 认领必须登录；广场显示"已有 N 人申请认领"；
- 分级揭示：核验第一题只问类别/颜色粗筛，答对才问细节。

## 7. 答辩话术（改完即可用）

> "我们对公开信息做了分级：拾者发布只公开类别、颜色和区域，物品照片以卡通占位呈现，页面上所有文字都是用户自己写的；AI 完全退到后台，只负责检索匹配和认领核验。这样冒领者从公开页面拿不到任何可复制的独特征。"

## 8. 诚实声明（团队内部知道即可，别写进答辩）

当前架构是前端直连云库，`detail`（隐藏细节）等技术字段仍可被 F12 读到，旧数据的 ai_desc 也仍在库里。
本改造解决的是**界面层的泄露**；要彻底根治需服务端字段白名单（L2 方案，见 ROADMAP"模型接入演进计划"）。
