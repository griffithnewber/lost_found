# 寻物官 · 阿寻（Lost & Found Agent）

对话式失物招领智能体：替拾者登记捡到的物品，替失者匹配丢失的物品，并在交接前用「隐藏特征核验」确认来者真的是失主。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **对话式拾物登记**：自然对话收集类别、颜色、地点、时间、公开说明与隐藏细节，整理成结构化记录（可对接云数据库 `lost_items` 表）。
- **双向匹配**：失者用一句话或一张图描述丢失物，按「公开信息 + 隐藏细节」两路信号排序匹配，解释理由时只引用公开信息。
- **防冒领核验**：从隐藏细节提炼「只有真失主答得出」的问题，三次机会，拒绝理由绝不透露答案，含糊一律不通过。
- **交接引导**：核验通过后给出交接建议并生成交接凭证。
- **隐私分级**：公开字段（类别/颜色/地点/时间/公开说明/编号）与隐藏字段（隐藏细节）严格分离，隐藏细节永不对外展示。

## 使用示例

- 「我在操场捡到一副黑色耳机，想登记招领」
- 「我丢了一张写有名字的证件卡，帮我找找有没有人捡到」
- 「我来认领那副黑色耳机，可以核验一下特征吗」

- 大小：单张不超过 500KB

## 设计背景

本智能体源自一个已上线的失物招领 Web 应用（静态页 + 云数据库 + AI 核验）的对话化改造：网页版中「防冒领核验」「隐私分级」「AI 拒答不泄题」等经过实战修补的规则，全部沉淀为本智能体的行为准则。

## 安装

将专家包目录放到专家目录下：

```
~/.workbuddy/plugins/marketplaces/my-experts/plugins/lost-found-assistant/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
python3 scripts/package_expert.py <expert-dir>
```
